# Brevin Muhatia — Portfolio

A dark bento-style personal portfolio inspired by the supplied reference UI.

## Files
- `index.html` — all portfolio content
- `style.css` — layout and visual design
- `script.js` — current year + placeholder link helper

## Replace these placeholders
1. CV link in `index.html`
2. Secondary school name/year
3. Primary school name/year
4. Any social links marked as placeholders
5. Profile photo URL if you want a local image instead

The current profile image uses the Dropbox image URL already present in the supplied portfolio.
